## 📌 Project Overview

Loan defaults are a major challenge for financial institutions. This project analyzes borrower characteristics and loan information to identify the factors that contribute to loan defaults and provides data-driven recommendations to reduce lending risk.

---

## 🎯 Business Objective

- Identify key factors influencing loan defaults.
- Analyze borrower profiles and loan characteristics.
- Build an interactive Tableau dashboard.
- Generate business recommendations to improve lending decisions.

---

## 📂 Dataset Overview

| Attribute | Description |
|-----------|-------------|
| Source | Lending Club Loan Dataset |
| Records | Loan applications |
| Features | Income, Loan Amount, Interest Rate, Grade, Purpose, Home Ownership, Employment Length, Loan Status |

## 🔍 Key Insights

- Lower credit grades experienced significantly higher default rates.
- Borrowers with higher interest rates were more likely to default.
- Certain loan purposes showed greater lending risk.
- Income alone was not a strong predictor of loan repayment.
- Loan grade was one of the strongest indicators of default.

---

## 💼 Business Recommendations

- Strengthen affordability assessments for high-risk borrowers.
- Apply stricter lending criteria for lower credit grades.
- Use risk-based pricing models.
- Improve borrower screening using predictive analytics.
- Monitor high-risk loan segments more closely.
